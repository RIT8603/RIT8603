## Projects

**[Plant Disease Detection System](https://github.com/RIT8603/Plant-Disease-Detection-System)** — Classical ML pipeline using handcrafted color, texture, and edge features, trained on 87,800+ leaf images across 38 classes. 84.77% validation accuracy, served via Flask API with a React frontend.
[Live demo](https://plant-disease-frontend-9zza.onrender.com/)

**[Book Recommendation System](https://github.com/RIT8603/Book-Recommend-System)** — Hybrid recommender combining popularity-based filtering for cold starts with item-similarity collaborative filtering, trained on the Book-Crossing dataset. Admin dashboard on Supabase for on-demand retraining.
[Live demo](https://book-recommend-system-blsz.onrender.com/recommend)

**[Customer Churn Prediction](https://github.com/RIT8603/churn_prediction)** — Compared 5 algorithms (Logistic Regression, Decision Tree, Random Forest, Gradient Boosting, XGBoost) on 7,043 Telco records. Logistic Regression selected as best model: 80.48% accuracy, ROC-AUC 0.846, F1 0.595. Deployed as a live inference app.
[Live demo](https://churn-prediction-3ro1.onrender.com/)

**[GeminiDecode](https://github.com/RIT8603/GeminiDecode)** — Multilingual document intelligence app for structured extraction, translation, and AI-generated insights from uploaded documents/images, powered by the Google Gemini API with a Streamlit interface.
